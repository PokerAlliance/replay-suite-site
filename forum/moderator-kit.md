# Moderator kit

Thread A (the showcase) is locked once posted, and only moderators can change it. This file
holds the two messages you will need. Keep them short: a moderator should be able to act on
either one in under a minute.

## 1. The lock request (send right after posting Thread A)

> Hello, I've just posted the Replay Suite showcase thread in General Poker Discussion:
> THREAD-A-URL
>
> As we discussed, could you lock it so it stays a clean introduction? All questions, bug
> reports and ideas go to the open discussion thread instead, which the showcase links to:
> THREAD-B-URL
>
> Thank you very much for your help with this.
> Badr (ThonBl7ror)

## 2. A change request (only if Thread A ever has to change)

Thread A is built to never need one: it holds no version numbers or dates, every link points
at a page that stays current by itself, and its images come from the website. Before
asking, check that the change can't be made on the website instead.

If it really must change, send exactly this, filled in. One change per message. Copy the
old text from the post itself, not from memory, so the moderator can find it with Ctrl+F.

> Hello, could you make one small change to the locked Replay Suite showcase post?
> THREAD-A-URL
>
> **Replace this text:**
> ```
> (the exact old sentence, copied from the post)
> ```
> **With this:**
> ```
> (the exact new sentence)
> ```
> **Why:** (one line)
>
> Nothing else in the post changes. Thank you!
> Badr (ThonBl7ror)

For an image change, say which image (its position, e.g. "the third picture, the replayer")
and attach the new image to the message.

## What never needs a moderator

- **A new version.** Thread A's download button always serves the newest version, and the
  Versions page lists them all. Announce it as a reply in Thread B.
- **Bugs and ideas.** They live on the website's Status page and in Thread B.
- **The videos.** The "Watch the video tour" card links to the website's Videos page, which
  shows them as soon as they are added.
